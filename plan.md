# Face Variants

Below is the explaination and proposed implementation of each varying face branch (A, B, C).

## Branch A

Branch A contains a script that will create a large amount of shapes with slightly altered coloring, forming a visible moustache on the face.

Implementation explored on branch A, separate from main. Final product was straight forward to create, and I purposefully lagged iterations behind to make an interesting line shape.

## Branch B

Branch B will add two new assets to the project, a transparent crown and robe. The crown will overlay the face on its head, while the robe will appear behind the face.

Implementation explored on branch B, seperate from main. Final product fits the face quite well. Had to use a super hero cape asset as a replacement, but you really couldn't tell within the context. Should explore load times for varied network speeds.

## Branch C

Branch C will utilize gradients and Bézier curves to display black-gray frosted sunglasses on the face.

Implementation explored on branch C. seperate from main. Originally planned to make an array of working pieces for the glasses, but ended up simply using two strokes and their derived area for the lens appearance.
