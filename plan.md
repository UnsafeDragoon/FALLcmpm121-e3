# Face Variants

Below is the explaination and proposed implementation of each varying face branch (A, B, C).

## Branch A

Branch A contains a script that will create a large amount of shapes with slightly altered coloring, forming a visible moustache on the face.

## Branch B

Branch B will add two new assets to the project, a transparent crown and robe. The crown will overlay the face on its head, while the robe will appear behind the face.

## Branch C

Branch C will utilize gradients and Bézier curves to display black-gray frosted sunglasses on the face.
